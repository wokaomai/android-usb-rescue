# 开发说明

## 模块

- `app.py`：tkinter 界面、坐标映射、串行 USB 工作线程与触点释放。
- `usb_transport.py`：libusb 加载、准确设备筛选、AOA HID 注册与有限输入动作。
- `mtp_reader.py`：MTP 只读事务、目录扫描、截图下载和一次完整重扫。
- `reference_catalog.py`：本机图片目录/清单校验。
- `local_api.py`：可选的本机文件请求接口。
- `settings.py`：数据目录与本机设置。

## 约定

所有手机操作由同一个 USB 工作线程完成，不在并行进程里争用接口。鼠标坐标按实际绘制区域转换；留白不能转发为手机触摸。

截图回读只遍历 `DCIM/Screenshots` 与 `Pictures/Screenshots`，遵守元数据、文件大小、对象数量和时间上限。遇到无效句柄或目录变化时废弃半轮结果，最多完整重新扫描一次；持续变化则报错，不把已扫描部分称为最新图片。

“已发送”只表示 USB 报告完成。“存储已开放”表示 MTP 返回了可用存储。“已取回图片”必须有完整文件、格式校验和实际时间信息。这些状态不代表实时投屏，也不代表页面上的具体操作已经成功。

默认启动不连接手机；默认鼠标暂停；本机接口需要显式启用。任何新增恢复动作都应保持这些边界。

## 仓库数据

只提交程序、文档和自包含的合成测试夹具。个人截图、设备序列号、运行状态、聊天记录、账号/网络标识和凭据不属于发布内容。第三方二进制通过正式依赖安装，不复制当前电脑上的驱动或 DLL。
